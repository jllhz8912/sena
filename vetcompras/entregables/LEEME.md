# Entregables — Aplicativo Sistema de Control 2.0

| Archivo | Para quién | Para qué |
|---|---|---|
| `SistemaControl-2.0.0-portable-windows.zip` | Cliente | Instalador para Windows. Pide activar la licencia del equipo al abrir. Datos en `C:\Users\<usuario>\SistemaControl\datos`. |
| `Manual-de-Usuario-Sistema-de-Control-2.0.pdf` | Cliente | Manual paso a paso (73 páginas, 67 pantallazos), incluye activación de la licencia y configuración de la marca. |
| `Videos-Sistema-de-Control-2.0.zip` | Cliente | 14 videos de capacitación + LEAME. |
| `Plantilla_Compras_SistemaControl.xlsx` | Cliente | Plantilla Excel para Cargar Compras. |
| `Sistema-de-Control-2.0-DEMO.html` | Prospectos | Demostración sin licencia (máx. 60 ventas y 60 compras, datos en el navegador). |
| `Guia-del-vendedor-Licencias-Sistema-de-Control-2.0.pdf` | Vendedor | Cómo emitir licencias, casos frecuentes y protección jurídica. |

Herramienta del vendedor: `../herramientas/Generador-de-licencias.html` (requiere el archivo
`CLAVE-PRIVADA-Sistema-de-Control.json`, que **no** está en el repositorio).

Instalación: extraer el zip → doble clic en "Instalar en este PC.bat" → icono "Sistema de Control" del escritorio → activar licencia.
